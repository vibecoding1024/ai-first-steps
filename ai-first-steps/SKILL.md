# AI 零基础入门

把用户眼前的问题做成一页可以独立阅读的小课。默认用简体中文，用户指定其他语言或篇幅时按其要求调整。像对第一次接触电脑术语的家人解释，保留准确的词义和自然的口吻。

## 写清楚再排版

- 开头用一句短话讲明白它是什么，再讲一个生活场景里它能帮上什么忙。术语首次出现时用常用词解释，缩写的英文全称可放在次要位置。
- 用读书、做饭、记事或上学等熟悉的情景打比方。说清比方里的事物分别对应什么，再补充一条会影响理解的真实条件。例子涉及外部工具时，写清连接成功和权限范围等必要条件，示意结果用「比如」标出。
- 单个概念只讲这一个问题。比较多个概念时，先分别解释，再用同一个场景展示各自的分工。大模型是训练规模较大的 AI 模型，大语言模型是其中专门处理语言的一类。Skill 提供可复用的任务说明和相关材料。MCP 是 AI 应用连接外部工具或资料的一种通用标准。
- 简单问题留一句话帮助回忆即可。适合练习的主题可加一道能应用刚学内容的题，把答案和理由放进可展开区。用户要系统入门时，按由浅到深拆成短课。
- 涉及具体产品的功能、版本、配置或权限时，先核对官方资料。实际引用的来源放在页面末尾，供读者查阅。

## 交付 HTML 学习页

1. 读取 [学习页模板](assets/lesson-template.html)，复制到用户指定的位置，默认使用当前工作区。根据主题给文件取一个易辨认的名字，避免覆盖现有文件。
2. 填好标题和正文，按内容选用章节卡、例子、对照或折叠答案。只有在多节内容确实需要跳转时保留目录。移除模板注释和未用区块，可根据主题调整配色和插图。
3. 生成单个 UTF-8 HTML 文件，内嵌样式，核心内容离线可读。优先用原生 HTML 完成跳转和折叠。检查占位符、链接、标题层级和窄屏布局。能做浏览器预览时检查实际页面。
4. 在聊天中给一句核心解释，并附上可点击的本地 HTML 文件链接。用户明确要求只在聊天里解释时，按其要求输出。
